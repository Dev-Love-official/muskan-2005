# Muskan Premium Love Website 💖🧸

A polished romantic website made with HTML, CSS, and JavaScript.

## Features

- Premium glassmorphism design
- Floating teddy bears, hearts, sparkles
- Funny moving “No” button
- “No” button grows the “Yes” button
- Love meter
- Optional photo reveal
- Mini heart-catching game
- Date plan selector
- Date picker
- Punjabi-English typed love letter
- Promise section
- Confetti ending
- Save plan button
- Optional background music

## How to run in VS Code

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right click `index.html`.
5. Click **Open with Live Server**.

## How to add her picture

1. Open the `assets` folder.
2. Add her photo.
3. Rename it exactly:

```txt
muskan.jpg
```

The website will automatically show it.

## How to add music

1. Put an mp3 file inside the `assets` folder.
2. Rename it exactly:

```txt
music.mp3
```

Click the music button on the website.

## GitHub Pages

Upload these files/folders to GitHub:

- `index.html`
- `style.css`
- `script.js`
- `assets/`
- `README.md`

Then go to:

Settings → Pages → Deploy from branch → main → /root → Save
